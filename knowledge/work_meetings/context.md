# Work Meetings Context

Contesto incrementale unico per tutte le riunioni di lavoro.

Usare questo contesto per riunioni generiche, riunioni tecnico/funzionali, flussi documentali, database, rilasci e domini applicativi come IMU, TARI o SIGE.

Non creare sottocartelle di dominio per IMU, TARI, SIGE, Libra, STARDAS, DoQui Acta o termini simili. Se questi termini diventano approvati, mantenerli nei file di questo contesto unico.

Questo materiale e' operational metadata: puo' guidare normalizzazione e analisi, ma non deve essere riportato come contenuto della riunione.
