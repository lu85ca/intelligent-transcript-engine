# Webinar Recipe

Usa questa recipe quando la trascrizione rappresenta un webinar, una presentazione educativa o una sessione formativa.

## Quando usarla

- Webinar live o registrati.
- Presentazioni didattiche, workshop, masterclass o sessioni formative.
- Contenuti con spiegazioni, framework, esempi e Q&A.

## Segnali da riconoscere

- Introduzione di relatore, tema o pubblico.
- Struttura didattica con sezioni, framework o step.
- Domande del pubblico o risposte del relatore.
- Citazioni di strumenti, modelli, esempi o risorse.

## Output Markdown

- Titolo
- Tipo contenuto e confidence
- Tema
- Concetti chiave
- Framework o modelli
- Esempi
- Strumenti citati
- Domande del pubblico
- Takeaway
- Azioni applicabili
- Limiti della fonte

## Campi JSON

- `title`
- `content_type`
- `theme`
- `summary`
- `key_concepts`
- `frameworks`
- `examples`
- `tools_mentioned`
- `audience_questions`
- `takeaways`
- `applicable_actions`
- `source_limitations`

## Cosa non inventare

- Non inventare relatore, titolo, strumenti o framework.
- Non trasformare esempi ipotetici in raccomandazioni operative.
- Non aggiungere domande del pubblico se non compaiono nella trascrizione.
- Usa `non rilevato` per informazioni assenti o poco chiare.
